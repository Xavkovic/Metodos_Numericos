# Instrucciones para compilar y ejecutar el proyecto en Java-Metodos Numericos-Metodos Numericos

Sigue estos pasos desde la terminal (CMD o PowerShell) para compilar y ejecutar el sistema de ecuaciones lineales:

1. Ubícate dentro de la carpeta que contiene los archivos fuente (por ejemplo, `Ecuaciones_lineales`).
2. Compila todos los archivos `.java` escribiendo:
   ```bash
   javac *.java
